# Skill 07 - Designing IP Addresses for Castle Rysen

This skill focused on the fundamentals of IPv4 addressing and subnetting. I learned how IP addresses are structured, the difference between network and host portions, and how subnet masks define broadcast domains.

I also designed the initial IP addressing scheme for the Castle Rysen Enterprise Network, creating a scalable addressing plan that supports multiple cafés, districts, fallout shelters, and central offices while leaving room for future expansion.
