# Initial IP Addressing Design

## Overview

This exercise focused on designing the initial IPv4 addressing plan for the Castle Rysen Enterprise Network.

The objective was to create a scalable addressing scheme that could support multiple cafés within each district, multiple districts within each fallout shelter, and multiple fallout shelters connected to a central office while maintaining a logical and expandable structure.

No Packet Tracer topology was used during this skill. The focus was on planning and documenting the enterprise addressing strategy before network deployment.
