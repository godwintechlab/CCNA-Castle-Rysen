# Skill 04 – Network Design and Communication Models

## Overview

This skill focuses on enterprise network design and communication models. It covers the OSI and TCP/IP models, layered network communication, three-tier enterprise architecture, and the overall design of the Castle Rysen enterprise network.

---

## Skills Practised

- Understanding the OSI reference model
- Understanding the TCP/IP protocol
- Mapping protocols to network layers
- Following data flow through each layer
- Understanding encapsulation and decapsulation
- Understanding three-tier, two-tier and spine and leaf design.
- Designing enterprise networks using the three-tier architecture
- Planning the Castle Rysen enterprise network
- Applying structured network design principles
