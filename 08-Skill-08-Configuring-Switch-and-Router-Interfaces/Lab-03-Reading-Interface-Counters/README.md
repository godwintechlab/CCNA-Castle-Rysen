# Lab 03 - Reading Interface Counters

## Overview

In this lab, I learned how to read and interpret Cisco interface counters to assess the health of a network connection. I examined interface statistics such as speed, duplex, input and output errors, CRC errors, collisions, interface resets, and traffic counters to determine whether an Ethernet link was operating correctly. I also verified connectivity using the ARP table and MAC address table to confirm that devices had learned each other's addresses correctly. Finally, I compared a healthy interface with a duplex mismatch example to understand how physical and configuration issues appear in interface statistics. This lab gave me practical experience using interface counters to verify network performance and troubleshoot common Ethernet problems.
