# Configuring Router Interfaces

## Overview

This lab focused on configuring the basic interfaces of a Cisco router for deployment in the Castle Rysen network. I configured the LAN-facing interface, secured the router with authentication, added interface descriptions, and prepared the WAN interface for future use. I verified connectivity between the router and the management switch using Cisco IOS commands and ping tests. By the end of the lab, the router was fully configured and ready for integration into the network.
