# Lab 02 - Configuring Router Interfaces

## Overview

In this lab, I configured the basic interfaces of a Cisco router ready for deployment in the Castle Rysen network. I assigned IP addresses to the LAN interface, configured local authentication, added interface descriptions, and prepared the WAN interface for future connectivity. After completing the configuration, I verified the router's interface status, checked connectivity with the management switch, and confirmed everything was working using Cisco IOS show commands and ping tests. This lab gave me practical experience configuring, verifying, and securing a Cisco router before it was integrated into the network.
