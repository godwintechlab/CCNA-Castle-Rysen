# Lab 01 - Configuring Switch Interfaces

## Overview

In this lab, I configured two Cisco access switches ready for deployment in the Castle Rysen network. I added interface descriptions, configured the management IP addresses, and adjusted the duplex settings on the required interfaces. After making the changes, I verified the switch status, checked connectivity using Cisco IOS show commands, and confirmed everything was working with ping tests. I also explored the basics of remote management using both Telnet and SSH. This lab gave me practical experience configuring and verifying Cisco switches before they are put into production.
