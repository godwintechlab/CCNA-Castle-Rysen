# Configuring Switch Interfaces

## Overview

This lab focused on preparing Cisco access switches for deployment in the Castle Rysen network. I configured interface descriptions, assigned management IP addresses, and adjusted duplex settings on active interfaces. I verified switch status and connectivity using Cisco IOS show commands and ping tests. The lab also introduced basic remote management concepts using Telnet and SSH. By the end of the lab, both switches were ready for management and production deployment.
