# Skill 08 - Configuring Switch and Router Interfaces

This skill focused on configuring, verifying, and troubleshooting switch and router interfaces using Cisco IOS. I learned how to configure Layer 2 switch interfaces and Layer 3 router interfaces, assign IPv4 addresses, enable interfaces, and verify connectivity using a variety of operational commands.

I also learned how to configure interface speed and duplex settings, understand the effects of duplex mismatches, identify interface errors using interface counters, and troubleshoot common physical layer issues such as CRC errors, collisions, and cabling faults. Throughout the skill, I strengthened my understanding of interface statistics, Ethernet operation, and bandwidth calculations while completing several hands-on configuration and troubleshooting labs.
