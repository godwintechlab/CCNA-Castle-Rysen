# Skill 01 – Using Packet Tracer

## Overview

This lab introduced Cisco Packet Tracer and the basic concepts of network simulation. I explored the interface, built my first network topology, and became familiar with the tools that will be used throughout the Castle Rysen Enterprise Network project.

## Skills Practised

- Installing Cisco Packet Tracer
- Navigating the workspace
- Creating a basic network topology
- Connecting network devices
- Saving and managing Packet Tracer projects
