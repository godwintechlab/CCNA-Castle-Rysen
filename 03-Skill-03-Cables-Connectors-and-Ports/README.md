# Skill 03 – Cables, Connectors, and Ports

## Overview

This skill focuses on the physical infrastructure of a network. It covers networking standards, copper and fiber optic cabling, cable selection, network diagrams and the physical installation of devices within the Castle Rysen District Shop.

---

## Skills Practised

- Understanding network standards
- Learned about MAC addresses, Hub, CSMA/CD
- Working with bits, bytes and network speeds
- Identifying copper cabling standards and characteristics
- Selecting straight-through and crossover cables
- Understanding Auto MDI-X
- Understanding fiber optic cabling and SFP modules
- Creating basic network diagrams
- Physical network installation concepts
- Building the District Shop network in Cisco Packet Tracer
