# Skill 02 – Assembling Your Network Equipment

## Overview

In this skill, I analysed the business requirements for the Castle Rysen Coffee enterprise network before beginning the physical network deployment.

The network must:

- Connect the Central Office (~200 users), Fallout Shelters (~50 users each) and District Shops (~15 users each).
- Provide secure and resilient connectivity between all sites.
- Support both wired and wireless networking.
- Provide local Plex-based media streaming for customers in each District Shop.
- Support video surveillance with 3–5 IP cameras at each District Shop.
- Be scalable and reliable to support future business growth.

Understanding these requirements helped me identify the purpose of each network device and how the enterprise infrastructure will be assembled throughout the project.

## Skills Practised

- Analysing business requirements
- Understanding enterprise network design
- Understanding LAN and WAN environments
- Identifying routers, switches and wireless devices
- Understanding clients and servers
- Understanding firewalls and network security
- Planning physical network infrastructure
