# CCNA Castle Rysen Enterprise Network

## Overview

This repository documents my journey through the Cisco CCNA by designing and implementing the enterprise network for **Castle Rysen Coffee**.

The network is built incrementally as I progress through the course, with each skill adding new technologies and configurations to the same enterprise environment.

---

## Project Goal

By the end of this project, I aim to design and implement a complete enterprise network that includes:

- Enterprise network design
- IPv4 and IPv6 addressing
- Layer 2 switching
- VLAN implementation
- Static and dynamic routing
- OSPF
- NAT
- Access Control Lists (ACLs)
- Layer 2 security
- DHCP, DNS, SSH and NTP
- SNMP and Syslog
- Wireless networking
- Network automation
- Complete Packet Tracer enterprise network

---

## Repository Structure

Each skill folder contains:

- README.md with an overview of the skill
- Packet Tracer lab files
- Screenshots or network diagrams (when applicable)
- Additional files as required
