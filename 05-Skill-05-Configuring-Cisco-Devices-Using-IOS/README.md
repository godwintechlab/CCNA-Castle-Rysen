# Skill 05 - Configuring Cisco Devices using IOS

## Overview

Learned how to navigate the Cisco IOS, perform basic device configuration, secure management access, understand Cisco memory, and save, restore, and reset device configurations.

---

## Skills Practiced

### Cisco IOS Navigation
- User EXEC mode
- Privileged EXEC mode
- Global Configuration mode
- Interface Configuration mode
- `exit`
- `end`
- Command history (Arrow Keys)
- Command auto-completion (`Tab`)

### Verification
- `show running-config`
- `show ip interface brief`

### Basic Configuration
- `hostname`
- `banner motd`
- `enable secret`
- `line console 0`
- `line vty 0 4`
- `login`
- `service password-encryption`
- `interface vlan 1`
- `ip address`
- `description`

### Cisco Memory
- RAM
- NVRAM
- Flash
- Running Configuration
- Startup Configuration
- Cisco boot process

### Configuration Management
- `write`
- `copy running-config startup-config`
- `write erase`
- `reload`
